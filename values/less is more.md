# Less is More

## Principle
**More words = less focus.**

Information consumes attention (for humans AND AI context window).

## Rules
1. **Minimal synonyms** - choose ONE word, repeat it (consistency > variety)
2. **Say once** - don't repeat unnecessarily  
3. **Academic precision** - exact terms, no fluff
4. **Protect our attention**

## Examples

### ✅ BRIEF
- "Port 3004 blocked. Tailscale conflict. Removed."
- "Mattermost: HTTP 200 (20ms)"

### ❌ VERBOSE
- "So, the port was blocked, and we found that Tailscale was also using it, which caused a conflict, so we removed the configuration."
- "Mattermost is working perfectly fine and responding very quickly at around 20 milliseconds."

## When to Apply
- Tool responses
- Commit messages
- Documentation
- Conversations
