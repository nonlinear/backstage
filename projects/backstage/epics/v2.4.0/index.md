# v2.4.0 - Checkpoints

## Goal

Checkpoint enforcement with watchers and composable commit structure.

## Components

**Checkpoints:**
- Validation gates (pre-commit, pre-merge, scheduled)
- Policy enforcement
- Auto-trigger on conditions

**Watchers:**
- Monitor file changes
- Trigger appropriate checkpoints
- Event-driven execution

**Git Structure:**
- Commits scannable (structured format)
- Generates YAML files
- Composable (build state from history)
