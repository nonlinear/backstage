# Injection Model

**Date:** 2026-03-09  
**Context:** Epic v3.1.0 - How values cascade and inject into agents

---

## Core Principle

**Values = Library (Single Source)**
- All values live in `~/Backstage/values/` (flat, no subfolders)
- YAMLs REFERENCE values (don't define them)
- Runtime RESOLVES references → reads .md files → injects into system prompt

**Cascading Resolution:** Company → Squad → Agent → Project

---

## 4-Level Composite

```
1. Company (backstage.yaml)
   values: [brevity, parity-contract, auditability, research, honesty]
   ↓
2. Squad (squads/design/squad.yaml)
   values: [jit, sprezzatura, visual-hierarchy]
   ↓
3. Agent (agents/design/uxr/agent.yaml)
   values: [research-ethics]
   ↓
4. Project (projects/hipaa-tool/project.yaml) - OPTIONAL
   values: [hipaa-compliance, patient-privacy]
```

## Runtime Resolution

### Pseudocode
```javascript
function getAgentComposite(agentId, projectId) {
  const composite = [];
  
  // 1. Company level
  const company = readYAML('~/Backstage/backstage.yaml');
  company.values.forEach(v => {
    composite.push(readFile(`~/Backstage/values/${v}.md`));
  });
  
  // 2. Squad level
  const squad = getSquadForAgent(agentId);
  const squadConfig = readYAML(`~/Backstage/squads/${squad}/squad.yaml`);
  squadConfig.values.forEach(v => {
    composite.push(readFile(`~/Backstage/values/${v}.md`));
  });
  
  // 3. Agent level
  const agentConfig = readYAML(`~/Backstage/agents/${agentId}/agent.yaml`);
  agentConfig.values.forEach(v => {
    composite.push(readFile(`~/Backstage/values/${v}.md`));
  });
  
  // 4. Project level (if agent working in project)
  if (projectId) {
    const projectConfig = readYAML(`~/Backstage/projects/${projectId}/project.yaml`);
    if (projectConfig.values) {
      projectConfig.values.forEach(v => {
        composite.push(readFile(`~/Backstage/values/${v}.md`));
      });
    }
  }
  
  return composite; // Array of markdown strings
}
```

### Injection
```javascript
const composite = getAgentComposite('design/uxr', 'hipaa-tool');
const systemPrompt = `
You are UXR Agent.

# Values (Policies - DO NOT EDIT)
# Auto-generated composite from 4 scopes

${composite.join('\n\n---\n\n')}

[rest of prompt...]
`;
```

## Why This Model?

**DRY (Don't Repeat Yourself):**
- Write value ONCE (`~/Backstage/values/brevity.md`)
- 21 agents reference automatically
- Change propagates instantly (next agent spawn)

**Simplicity:**
- Agent YAML = minimal (only agent-specific values)
- No need to list global/squad values

**Context-Aware:**
- Same agent behaves differently in different projects
- HIPAA project → extra compliance values
- Open source project → commons-licensing value

**Auditability:**
- Cache file = snapshot of composite (debugging)
- Timestamp = when composite was generated
- Git tracks value evolution (not composite)
