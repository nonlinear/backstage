# v2.5.0 - Checkpoints GUI

## Goal

GUI for checkpoint compliance and history.

## Components

**Compliance Dashboard:**
- Which checkpoints active
- Current compliance status
- Failed checkpoints (actionable)

**History View:**
- Checkpoint execution over time
- Trends (improving/degrading)
- Audit trail

**Triggers:**
- Visualize conditions
- What triggers what
- Manual override interface
