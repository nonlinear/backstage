## ✅ Completed

### Paperless Auto-Upload (2026-02-09)
**Status:** ✅ SHIPPED

**What it does:**
- Auto-upload scanned documents from iCloud Scans → NAS Paperless
- Runs daily 3am via system crontab
- OCR + indexing automatic
- Silent background operation

**Implementation:**
- Script: `~/.openclaw/workspace/scripts/paperless-auto-upload.sh`
- Cronjob: `0 3 * * *` (system crontab)
- Logs: `~/.openclaw/workspace/logs/paperless-upload.log`
- Docs: `~/.openclaw/workspace/parity/paperless-ngx.md`

**Key learnings:**
1. Ping blocked by NAS firewall → use port check (`nc -z`)
2. iCloud placeholders cause empty file errors → force download with `cat`
3. Paperless API returns UUID string (not JSON object)
4. 24h delay acceptable (Nicholas scans during commute)

**Test:** 10 PDFs uploaded successfully, deleted from iCloud
