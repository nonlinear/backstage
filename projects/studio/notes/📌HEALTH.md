# OpenClaw Workspace HEALTH

*Your attention secretary. Am I focusing on what matters?*

---

## 🎯 Core Question

**"Am I doing what I should be doing right now?"**

Not "is the code working?" — that's for work projects.  
This is: **"Is my attention in the right place?"**

---

## ✅ Green (Healthy Focus)

**Body First (NON-NEGOTIABLE):**
- [ ] **Ate** something today (before deep work)
- [ ] **Hydrated** (water nearby, drank in last 2h)
- [ ] **Moved** body at least once (walk, stretch, exercise)
- [ ] **Not working past midnight** (sleep > code)

**RULE:** Body needs trump work needs. Always.
- Hungry? → Eat first, work second
- Need exercise? → Workout first, code second  
- Need meditation? → Breathe first, email second

**Attention Management:**
- [ ] I picked ONE thing from available options
- [ ] I'm working on it (not context-switching)
- [ ] It aligns with my current priorities
- [ ] I have clear next steps

**Energy Alignment:**
- [ ] Task matches my current energy level
- [ ] I'm not forcing deep work when tired
- [ ] I'm not doing busy work to avoid hard things
- [ ] Break taken in last 2 hours

**Progress Tracking:**
- [ ] Today's memory file exists
- [ ] I know what I accomplished today
- [ ] Capability tracks updated if I made progress
- [ ] No circular debugging (check FAILED.md first)
- [ ] **Git commit** (when docs align with reality — capture state)

**Life Balance:**
- [ ] Exercised today (or scheduled)
- [ ] Meditated (or scheduled)
- [ ] No skipping meals (hunger = red flag)
- [ ] Body maintenance done (shower, meds, etc.)

---

## ⚠️ Yellow (Attention Drift)

**Warning Signs:**
- [ ] Opened 5+ browser tabs about "the perfect solution"
- [ ] Started 3 different tasks in last hour
- [ ] Researching instead of doing (analysis paralysis)
- [ ] Can't remember what I was doing before this

**ADHD Red Flags:**
- [ ] Hyperfocus on the wrong thing
- [ ] Interesting ≠ Important (squirrel!)
- [ ] Perfectionism blocking progress
- [ ] Avoiding the hard/boring part

**Action:**
1. Close all but 1 tab
2. Check ROADMAP: what did I choose?
3. Set 25-min timer, just do THAT
4. Update memory when timer ends

---

## 🔴 Red (Lost in the Sauce)

**Critical Attention Failure:**
- [ ] No idea what I'm supposed to be working on
- [ ] Haven't updated memory in 2+ days
- [ ] Working on something not in ROADMAP
- [ ] Feeling overwhelmed/scattered

**Rescue Protocol:**
1. **STOP.** Close everything.
2. Read `backstage/ROADMAP.md` top section
3. Pick ONE thing (smallest, easiest if overwhelmed)
4. Write it on paper: "I am doing [X] right now"
5. Set timer, start

**If still stuck:**
- Go outside for 10 minutes
- Call it a day (rest > forcing)
- Ask OpenClaw: "What should I focus on?"

## 🧠 ADHD-Specific Checks

### Hyperfocus Management
- [ ] Am I 3+ hours into same task without break?
- [ ] Did I forget to eat/drink/pee?
- [ ] Is this the ACTUAL priority or just interesting?

**If yes:** Set alarm for 30 min, take break when it rings.

### Context Switching Protection
- [ ] Did I finish/pause the LAST thing before starting this?
- [ ] Is there an open epic I abandoned?

**If yes:** Close current thing, finish or explicitly pause the old one.

### Decision Fatigue
- [ ] Am I re-deciding the same thing over and over?
- [ ] Stuck choosing between options?

**If yes:** Flip a coin, pick one, commit for 1 hour minimum.

### Dopamine Traps
- [ ] Am I "researching" (reading HN/Reddit/articles)?
- [ ] Organizing instead of creating?
- [ ] Optimizing tools instead of using them?

**If yes:** Set 5-min timer to finish current tab, then CLOSE and do real work.

## 🕐 Time-of-Day Checks

### Morning (Before noon)
- [ ] Picked today's ONE focus from ROADMAP
- [ ] Started with hardest/most important thing
- [ ] Not doing email/admin first (procrastination)

### Afternoon (Noon - 6pm)
- [ ] Still on the ONE thing, or consciously switched?
- [ ] Took lunch break
- [ ] Not spiraling in research rabbit holes

### Evening (6pm - midnight)
- [ ] Wrapped up or explicitly paused work
- [ ] Updated memory/CHANGELOG if I did something
- [ ] Not starting NEW things (low-energy trap)

### Late Night (After midnight)
- [ ] **GO TO SLEEP.**
- [ ] Seriously, nothing good happens after midnight.
- [ ] Save state, close laptop, hydrate, bed.

## 🎯 The Real Health Check

**One question:**

**"If I keep doing what I'm doing right now, will tomorrow-me thank me?"**

- ✅ **Yes** → Keep going
- ❌ **No** → Stop, check ROADMAP, pick something real
- 🤷 **Unsure** → Take break, come back with clarity

- ✅ "Exercise scheduled?" (if not done today)
- ✅ "When did you last drink water?" (hydration check)
- ✅ "It's midnight, wrap up" (sleep > finishing task)

**Use me to:**
- ✅ Reduce decision fatigue (I remember what you chose)

- ✅ Protect deep work (I can decline interrupts)
- ✅ **Enforce body care** (I remind, nag, celebrate self-care)

## 📝 Daily Ritual

**Start of work:**
1. Read ROADMAP "Available options"
2. Pick ONE
3. Tell OpenClaw: "I'm working on [X] today"
4. Set intention, start timer

**During work:**
- Every 90 min: Stand up, stretch, water
- Every 3 hours: Real break (outside/food)
- If stuck: Ask for help, don't spiral

**End of work:**
1. Update memory with what you did
2. Explicitly pause or mark done
3. Clear mental cache (brain dump if needed)
4. CLOSE LAPTOP.
