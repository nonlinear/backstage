## What We Are

**Not** a traditional agency. **Not** a startup chasing growth.

## Core Principles

### 1. Gestalt - Visual Hierarchy Communicates Structure

**What it means:**
- User understands the system just by looking
- No need to read instructions
- Animations obey gestalt logic (e.g., title grows, others fade = entering subset)

**Applied to:**
- **Website:** Tier status visually obvious (flagship = full color, experiments = muted)
- **Backstage:** Epic branches visually distinct from main
- **Products:** Design language = stability signal

**Philosophy:** If the user has to ask "where am I?", we failed.

---

### 2. Wayfinding - User Always Knows Where They Are

**What it means:**
- Orientation (where am I?)
- Route decisions (where can I go?)
- Mental mapping (how do I get back?)
- Closure (did I reach my goal?)

**Applied to:**
- **Website:** Breadcrumbs persist across page transitions, URLs reflect hierarchy
- **Backstage:** Epic notes link to ROADMAP, CHANGELOG shows history
- **Pipelines:** Agent knows which check it's on, which epic it belongs to

**Philosophy:** Lost users abandon. Clear paths build trust.

---

### 3. Sprezzatura - Effortless Elegance

**Etymology:** Italian Renaissance concept (Baldassare Castiglione, *The Book of the Courtier*)

**What it means:**
- Complex work appears simple
- Precision that looks casual
- Grace under pressure (no visible strain)

**Applied to:**
- **Website:** Microanimations feel effortless, but are carefully choreographed
- **Products:** DRY at user level (don't repeat yourself) - minimal gestures, maximum meaning
- **Process:** Extensive checks happen behind the scenes, user sees polished result

**Philosophy:** "The best design is invisible." - Don Norman

---

### 4. Just-in-Time (External + Internal)

**Two meanings:**

#### A) External (UX) - Features Appear When Needed

**What it means:**
- Don't show users features they don't need yet
- Reduce cognitive load
- Progressive disclosure

**Examples:**
- Cookie policy only appears when user changes language (not on landing)
- Translation button only appears if translations exist
- Sidebar only appears if article >500 words

**Philosophy:** Respect attention. Don't clutter. Reveal when relevant.

---

#### B) Internal (Workflow) - Triggers Detect Thresholds

**What it means:**
- System detects when epic is needed
- Proposes action, Nicholas approves
- Automation serves human decision

**Examples:**
- Article >500 words → Trigger suggests summarization epic
- Product promoted to Tier 3 → Trigger suggests translation epic
- 3+ articles per product → Trigger suggests navigation epic
- Flagship product stable → Trigger suggests custom branding epic

**Philosophy:** Automation detects, human decides. No autopilot without oversight.

## Product Tiers (Quality Signal)

**Problem:** How do we show experimental work without misleading users?

**Solution:** Explicit tier system (gestalt-based visual distinction)

### Tier 1: Flagship
- **Signal:** Maximum attention, full branding, detailed docs
- **Stability:** Production-ready or actively developed with commitment
- **Examples:** Site itself, Agregore, Backstage
- **CTA:** "Use", "Contribute", "Translate"

### Tier 2: Experiments
- **Signal:** Documented but unstable, disclaimer visible
- **Stability:** Take at your own risk
- **Examples:** Proof-of-concept tools, research prototypes
- **CTA:** "Test", "Give Feedback"

### Tier 3: Ideas
- **Signal:** Backstage only, minimal visibility
- **Stability:** Ideation phase, not yet built
- **Examples:** Epic notes, research sketches
- **CTA:** "Follow Progress"

**Philosophy:** Honesty > hype. User knows stability at a glance.
